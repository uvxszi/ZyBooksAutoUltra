Where models are installed

Models are saved in this browser profile’s IndexedDB storage for ZyBooks AutoUltra. They are not saved beside the extension files.

The model databases are webllm/model, webllm/config, and webllm/wasm. Use “Remove download” on a card to reclaim its space. Find your actual profile folder on vivaldi://version, chrome://version, or edge://version under Profile Path. Uninstalling the extension removes its browser-managed storage.

Storage & model quality

Size estimates cover model weights; tokenizer and browser cache overhead add a little more. GPU memory needs can exceed the listed baseline with longer contexts. The catalogue ranges from 0.5B to 13B parameters, including a 7B coding model. The older Llama 2 13B is a high-memory alternative, not a quality ranking. AI answers can contain mistakes; review the result before using it.

Removing a card removes its downloaded model when no other card uses that model. “Remove download” keeps the card. Keep the unpacked extension in a permanent folder when updating it.

The Windows message that WebGPU’s powerPreference is ignored is a browser warning, not an inference failure. This version omits that unused setting.
