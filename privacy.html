Privacy & support · Made by uvxszi

Privacy notice

Effective October 8, 2026 · Version 1.7.1

ZyBooks AutoUltra is an independent browser extension by uvxszi. Its purpose is to provide participation controls and a manual AI question workspace on zyBooks. It is not affiliated with zyBooks or Wiley.

Information handled

The extension reads rendered activity content, controls, and the current section’s navigation information to provide the features you use. Copy Element reads the text or dropdown you explicitly select. Clipboard text is read when you press Paste. The topic helper reads a limited set of page headings and activity excerpts when you press its star button.

Prompts and generated answers are kept in the open page’s memory. Preferences, model cards, API connection details, and downloaded models are stored in your browser profile. API model cards, including keys, are encrypted with AES-GCM using a non-extractable key stored in the extension’s private browser database. Model summaries in extension settings contain only a display name and model type. No API key is exposed through content-script settings.

Where information goes

Local browser models process prompts on your device. Installing models downloads configuration, tokenizers, and weights from Hugging Face and its delivery services; those services receive ordinary connection information such as your IP address and requested model. The extension’s JavaScript and WebAssembly code are included in the installed package.

If you select an API model, the endpoint you configure receives the prompt and optional topic prefix when you press Ask model. The topic helper sends its page excerpt to that same endpoint. API keys are sent to the endpoint you configured for authentication. A local LM Studio server receives requests on your own computer. Other providers’ handling and retention are governed by their policies and your settings with them. HTTPS is required for remote APIs; HTTP is supported only for localhost/loopback services.

Participation controls use the website’s normal interface. The website may record activity responses and completion through its own systems. The extension does not send prompts, browsing content, or diagnostic reports to uvxszi automatically. It has no advertising, analytics, sale of data, or cross-site browsing-history collection.

Your choices and deletion

Clear empties the question box. Clear answer empties only the answer box and stops an answer still being generated so it stays empty. These buttons do not erase text already copied to your system clipboard. Reloading or closing the zyBooks page clears the in-memory question and answer. Turn Off cancels extension work and releases local model memory; installed model files remain. Remove download removes the selected model’s cached files. Delete card removes its saved configuration and credentials. Optional embedded-site permissions can be revoked from the popup. Uninstalling the extension removes its browser-managed storage. API providers may retain copies already sent under their own policies.

Diagnostics and support

Diagnostic reports are generated locally only when requested. They contain extension/browser information, settings, activity structure and text, and run logs. Current form values, scripts, and common credential patterns are excluded, but remaining content may contain personal information. Review a report before sharing it. If you voluntarily submit a report for support, its contents are handled only to investigate your issue. Do not post secrets or private information to public support discussions.

For questions, privacy requests, or bug reports, use the Support section on this extension’s Chrome Web Store listing. No separate email address is embedded in the extension.

Limited Use

ZyBooks AutoUltra’s use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only for the features described here and support explicitly requested by the user, not advertising, sale, or unrelated purposes.

Updates that change data practices will be reflected in this notice and the extension’s public listing.
